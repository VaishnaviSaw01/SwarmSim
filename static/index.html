Watch a swarm change its mind.

SwarmSim seeds a population of simple agents from a topic string, drops them on a small-world social graph, and lets a plain weighted-average update rule run for N rounds — then reports whether, how fast, and which way the swarm settled.

The method

How it works

Four plain steps, each one a small Python module with no hidden model in it — see the README for the exact formula.

01 · seed.py

Seed

TF-IDF pulls the topic's top keywords; a small hardcoded word list scores them positive/negative into one bias number.

02 · environment.py

Environment

A small-world graph (networkx) seats every agent with local neighbors plus a few long-range shortcuts; opinions start scattered around the bias.

03 · simulate.py

Simulate

Each round, every agent's opinion becomes a stubbornness-weighted average of its neighbors' opinions, plus a little noise.

04 · evaluate.py

Evaluate

Variance, convergence round, opinion clusters, and a favorable/neutral/opposed split — scored, not eyeballed.

Why it's here

What it's actually good for

A whiteboard-simple environment, not a forecasting product — these are the honest use cases.

Message framing

Sandbox a framing before you send it

Run the same announcement worded two ways and compare the simulated lean — a cheap intuition check, not a survey replacement.

Teaching

Demonstrate opinion dynamics

Every rule is one line you can put on a whiteboard: graph topology, a weighted-average update, and threshold-based evaluation.

Extensibility

Swap in a smarter agent

The update rule is the only part that's "dumb." Replace it with an LLM-judged reaction and the graph, logging, and evaluation layers don't change.
